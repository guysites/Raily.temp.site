# Raily alternative website — visual revision 2

A standalone, static multi-page website concept for review. It does not connect to or modify the live Raily website.

## Pages
- `index.html` — homepage
- `platform.html` — platform overview
- `use-cases.html` — target audiences and business outcomes
- `stories.html` — customer stories
- `contact.html` — contact concept / placeholder

## Run locally
Open `index.html` in a browser. No build step or package manager is required.

## What's changed in visual revision 2
- Replaced the small, low-contrast headline system with large editorial typography and clearer hierarchy.
- Made the brand line “Empower agents. Keep control.” prominent in the homepage hero and supporting sections.
- Removed the decorative floating-node hero illustration and replaced it with a clear organization → Raily → AI agents diagram.
- Used the dark navy / blue / lime visual language of the “Meet Raily” section as a stronger design foundation across the site.
- Removed the invented circular logo mark. The current header uses a clean text wordmark until the exact approved Raily logo asset (SVG/PNG) can be supplied or extracted from the source website.
- Bundled Inter fonts locally so the design does not depend on an external font service.

## Before publication
- Replace the temporary text wordmark with the approved Raily logo asset.
- Connect the contact page to an approved email, calendar or CRM workflow.
- Confirm customer story wording, figures, logos and publication approvals.
- Review all product capability and deployment claims with the product team.
- Add approved privacy, legal and analytics details.
