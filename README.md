# Raily alternative website — visual revision 2

A standalone, static multi-page website concept for review. It does not connect to or modify the live Raily website.

## Pages
- `index.html` — homepage
- `platform.html` — platform overview
- `use-cases.html` — target audiences and business outcomes
- `stories.html` — customer stories
- `contact.html` — contact concept / placeholder

## Run locally
Open `index.html` in a browser. No build step or package manager is required.
